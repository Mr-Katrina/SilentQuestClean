# SilentQuest: Silent Hill VR

![SilentQuest Banner](assets/banner.png)

A VR port of *Silent Hill (1999)* for PC VR, rebuilt in Unreal Engine for a fully immersive survival horror experience.

## 🎮 Features
- **First-Person VR Gameplay** – Explore Silent Hill in a terrifyingly immersive perspective.
- **Modernized Controls** – Free movement and VR interaction optimized for comfort.
- **Recreated Atmosphere** – Faithful recreation of fog, lighting, and eerie ambiance.
- **Full Game Implementation** – All puzzles, combat, and story elements from the original game.
- **Adaptive Horror Mechanics** – Enhanced AI and dynamic scares tailored for VR.
- **Cutscenes in 2D VR Theatre** – Experience story moments without breaking immersion.

## 🛠 Installation
### **Requirements**
- A valid copy of *Silent Hill (1999)* (PS1)
- A VR headset (Quest, Index, Vive, or Rift supported)
- Windows 10/11

### **Setup Instructions**
1. **Obtain the game files**: You must legally own a copy of *Silent Hill (1999)*. The game will extract necessary assets at runtime.
2. **Download SilentQuest VR**: [Release Page](https://github.com/YourRepo/SilentQuest-VR/releases)
3. **Extract the contents** to a preferred directory.
4. **Launch `SilentQuest.exe`** and follow the setup instructions.
5. **Enjoy your nightmare in VR.**

## 🎮 Controls
| Action | VR Input |
|--------|---------|
| Walk | Left Joystick |
| Run | Press Left Joystick |
| Interact | A / X Button |
| Attack | Trigger Button |
| Open Inventory | Menu Button |
| Flashlight Toggle | Grip Button |
| Look Around | Head Movement |
